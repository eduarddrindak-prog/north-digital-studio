# pilaruStudio

The pilaruStudio website and portfolio, built with React, TypeScript and Vite.

## Development

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

## Available checks

```bash
npm run build
npm run lint
```

The repository contains the pilaruStudio main website and three independent portfolio concepts: VANTA, Maison Lenoir and Atelier Martin.
